# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting instead:

https://github.com/iovisor/bcc/security

Include the affected tool or library, the kernel and architecture, a
reproducer if one exists, and the impact you observed. We will use the
advisory to discuss and prepare a fix before it becomes public.

## Scope

This policy covers the bcc tools, the Python and C++ libraries, and the
libbpf-tools in this repository. Vulnerabilities in the kernel's BPF
subsystem or in libbpf itself should be reported to their respective
projects.
